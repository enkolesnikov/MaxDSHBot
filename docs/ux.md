# UX-аудит 1.4

Аудит проведён по коду, трём скриншотам интерфейса бота и локальному
`audit.jsonl` (команды за время жизни плагина). Шрифт/тема MAX не оценивались.

## Что было шумно

1. Заголовок `**DSH** · 20:03:28 · Создание плагина…` повторялся в каждом ответе.
2. «Фоновая задача: completed» с командой, ID и exit code — 4–5 строк на событие.
3. «Ответ дан в GUI» / «Ответ не получен (ошибка GUI)» — отдельные карточки.
4. 31 команда в меню и `/help` на 1114 символов.
5. Продвинутые команды (`/diff`, `/send`, `/approve`, TTS) на одном уровне с
   ежедневными.
6.approval-карточка содержала `callId`, причину до 500 символов и лишние строки.

## Решение

| Метрика | До | После |
|---|---|---|
| Команд в меню | 31 | 13 (включая `/brief` с 1.5) |
| `/help` | 1114 символов | 394 |
| `/help all` | — | 514 |
| Уведомлений по умолчанию | 6+ типов | final, errors, approvals/questions, budget |
| Служебных карточек на ход | до 2–3 | 0–1 |
| Заголовок | `**DSH** · 20:03:28 · title` | `🕒 20:03 · title` |

## Уведомления

По умолчанию выключены: subagent, jobs, goals, TODO. Включены: финальные
ответы, ошибки агента, approvals/questions, бюджетные алерты. Включаются
обратно в GUI → Plugins → dsh-max-notify → «Уведомления».

## Карточки

- Approval: `🔐 Разрешить bash?` + сессия + причина ≤200; без callId.
- Результат: `✅ Разрешено (GUI) · bash`.
- Job/subagent/goal: одна строка.
- Ошибка: заголовок + 1–3 строки, без стектрейса.
- Digest: «Сделано / Ждёт тебя / Деньги / Дальше».
- Финальный заголовок: `🕒 20:03 · title`.
